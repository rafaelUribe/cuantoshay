# Uno de cada cuántos

Calculadora demográfica: pon requisitos de pareja (edad, estatura, ingreso, escolaridad,
trabajo, patrimonio, tono de piel, atractivo físico) y estima cuántos hombres de 18 a 70
años en México los cumplen — a nivel nacional o por cualquiera de las 32 entidades — con
datos calibrados a cifras públicas del INEGI (Censo 2020, ENOE, ENADID, ENSANUT, ENIGH).

No es un producto del INEGI ni un censo de personas reales: es un modelo estadístico de
orden de magnitud, generado por simulación Monte Carlo sobre 1.2 millones de perfiles
sintéticos.

Sitio estático, un solo archivo (`index.html`), sin dependencias de build.
